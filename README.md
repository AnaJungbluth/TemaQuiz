# 🎓 TemaQuiz

TemaQuiz é uma aplicação que permite ao usuário **escolher um tema**, responder perguntas relacionadas ao tema, receber feedback instantâneo sobre suas respostas e manter um histórico de utilização.  

---

## 🛠 Tecnologias Utilizadas

- HTML  
- CSS  
- React  
- TypeScript  
- Integração com API da OpenAI

---

## 🔐 Configuração da OpenAI

Para que as funcionalidades de IA funcionem:

1. Crie uma chave no site da OpenAI.  
2. No arquivo `openai.ts`, substitua o valor `'chave-openAI'` pela sua chave pessoal.

---

## 🚀 Como Rodar Localmente

1. Clone este repositório  

   ```bash
   git clone https://github.com/AnaJungbluth/TemaQuiz.git
   cd TemaQuiz
   ```

2. Instale as dependências
   
   ```bash
   npm install
   ```

3. Inicie a aplicação
   ```bash
   npm run dev
   ```
